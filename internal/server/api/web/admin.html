网页登录（SSO）

有些网关（如使用 SAML 单点登录的 AnyConnect）要求在网页上登录，登录结果是一个只存在于网关网站上的 cookie。浏览器出于安全原因不允许管理后台直接读取别的网站的 cookie，所以需要借助下面这个书签把它带回来。

一次性准备：把这个按钮拖到浏览器的书签栏。

VPN 网关回传

每次登录：

  1. 在「隧道」页点「连接」，等出现「需要网页登录」。
  2. 点「打开登录页」，在新标签页里完成登录（包括手机验证）。
  3. 登录完成、页面停在网关自己的网站上（常见提示是“请关闭此窗口”）时，点书签栏上的「VPN 网关回传」。
  4. 页面会跳回这里并自动提交，隧道随即开始连接。

书签只在你点它的那一刻读取当前网关页面的 cookie，并通过网址的 # 部分交给本页；它不会发往任何其他地方，也不会经过服务器日志。如果书签提示找不到 cookie，可以在登录页按 F12 → 应用/存储 → Cookie 里复制对应的值，粘贴到隧道卡片上。
